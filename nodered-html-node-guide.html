1. 概要

HTML ノードは、HTMLドキュメントから特定の要素を抽出するノードです。CSSセレクタを使って、Webページから必要なデータを取り出す「Webスクレイピング」に使用します。

本から特定の章を探すことに例えると：HTML ノードは本の目次を使って特定の章を探すようなものです。「第3章」「著者紹介」など、目的の部分をピンポイントで取り出せます。

HTTP Request → HTML → Debug

ポイント:

  • CSSセレクタでHTML要素を指定
  • 複数の要素がマッチした場合は、既定の設定では配列で出力
  • Webスクレイピングの基本ツール
  • テキストだけでなく属性値も取得可能

動作を図で見る

html ノードは、HTML の文字列から、セレクタで指定した要素を取り出します。

2. 設定詳細

主要プロパティ

エディターは上から順に、入力 HTML の取得元、抽出方法、出力先を指定する欄が並ぶ。

設定項目説明既定値
プロパティ解析する HTML が入っている入力プロパティ。msg のどこに HTML 文字列があるかを指すmsg.payload
抽出する要素取り出したい部分を指す CSS セレクタ（h1、.title など）。次章で詳しく解説する（空）
出力マッチした要素から何を取り出すか。下の「出力の種類」から選ぶ要素内のHTML
配列化した1つのメッセージ／要素毎の複数のメッセージ「出力」欄の下にあるセレクタ。複数の要素がマッチしたとき、結果を1つの配列にまとめて1メッセージで送るか、要素ごとに分けて複数メッセージで送るかを切り替える配列化した1つのメッセージ
対象抽出結果を書き込む出力先プロパティmsg.payload
HTMLコンテンツのプロパティ名「出力」で「要素やHTMLコンテンツの属性オブジェクト」を選んだときだけ表示される。属性に加えて要素内の HTML 本文を格納するキー名（接頭辞）_
名前エディター上のノード表示名（空）

「出力」の種類

「出力」セレクタで選べる4つの取り出し方。例は <p class="lead"><b>太字</b>テキスト</p> の p 要素を抽出した場合を示す。

選択肢説明例
要素内のHTMLマッチした要素の内側の HTML をそのまま返す<b>太字</b>テキスト
要素のテキストのみタグを除いたテキストだけを返す太字テキスト
要素の全ての属性要素が持つ属性をオブジェクトにまとめて返す{ "class": "lead" }
要素やHTMLコンテンツの属性オブジェクト属性オブジェクトに要素内の HTML 本文も加える（本文は「HTMLコンテンツのプロパティ名」で指定したキーに入る）{ "class": "lead", "_": "<b>太字</b>テキスト" }

3. CSSセレクタの基本

基本セレクタ

セレクタ説明例
要素名タグ名で選択p, div, a
.クラス名class属性で選択.article, .title
#IDid属性で選択#header, #main
[属性]属性の有無で選択[href], [data-id]
[属性=値]属性値で選択[type="text"]

組み合わせセレクタ

セレクタ説明例
A BAの子孫のBdiv p（div内の全p）
A > BAの直接の子のBul > li（ulの直下のli）
A, BAまたはBh1, h2（h1とh2両方）
A.classAでクラスがclassp.intro

便利なセレクタ

/* n番目の要素 */ li:nth-child(1) /* 1番目のli */ li:nth-child(odd) /* 奇数番目のli */ li:first-child /* 最初のli */ li:last-child /* 最後のli */ /* 属性の部分一致 */ [href^="https"] /* httpsで始まる */ [href$=".pdf"] /* .pdfで終わる */ [href*="example"] /* exampleを含む */

フローの読み解き

フローには、公式サンプルの4つの例が、上から順に並んでいます。それぞれの先頭に、英語の comment ノードがあります。どの例も、「例N: 実行」（inject）のボタンで動かし、「例N: 結果」（debug）に結果が出ます。4つの例は、同じ HTML（「HTML text」という名前の template ノードに書いてある、果物3つの箇条書き）から、class="Item" の付いた li 要素を取り出します。違うのは、取り出した結果の出し方です。

例 comment ノードの見出し（意味） ノードの並びと、html ノードの設定 「例N: 結果」に出るもの
例1 Extract array of HTML element by CSS selector（CSS セレクタで、HTML の要素を配列として取り出す） 「例1: 実行」→「HTML text」（template）→ html →「例1: 結果」。「抽出する要素」は .Item、「出力」は「要素内のHTML」と「配列化した1つのメッセージ」 ["Apple","Orange","Banana"]（配列が1つ）
例2 Extract sequence of HTML element by CSS selector（メッセージ列として取り出す） 並びは例1と同じ。「出力」の2つ目の欄が「要素毎の複数のメッセージ」 Apple、Orange、Banana（別々の msg が3つ）
例3 Extract array of HTML element by CSS selector specified in message（セレクタを msg で渡して、配列として取り出す） 「例3: 実行」→「HTML text」→ change → html →「例3: 結果」。change が msg.select に .Item を入れる。html ノードの「抽出する要素」は空にしてある ["Apple","Orange","Banana"]（例1と同じ）
例4 Join extracted sequence of HTML element using join node（取り出した列を、join ノードでつなげる） 「例4: 実行」→「HTML text」→ html → join →「例4: 結果」。html ノードは例2と同じ設定。join は、「動作」が「手動」で、カンマ区切りの文字列にまとめる設定 Apple,Orange,Banana（文字列が1つ）
  • 例1と例2の違い: 同じ3つの要素が、例1では1つの msg の配列に、例2では3つの msg に分かれて出ます。後ろで1件ずつ処理したいときは例2の設定、まとめて扱いたいときは例1の設定を使います。
  • 例3: msg.select が使われるのは、html ノードの「抽出する要素」が空のときだけです。欄に値があるときは、欄の値が優先されます。取り出す要素をフローの途中で決めたいときに使います。
  • 例4: html ノードは、分けて出す msg のそれぞれに、列の印（msg.parts。全部で何個のうちの何番目か）を付けます。join は、この印を見て、3つそろったところで1つにまとめます。

フローの読み解き

応用フローは、3つの部分に分かれています。各部分の先頭にある comment ノードの名前が、下の表の「部分」に当たります。3つの inject はどれも「実行」という同じ名前なので、comment ノードのすぐ下にあるものを押してください。

部分 ノードの並び html ノードの設定と、debug に出るもの パターン
基本: HTMLからテキスト抽出 「実行」（inject）→「サンプルHTML」（template）から、「h1抽出」「全p抽出」「リンクURL抽出」の3つの html ノードへ同じ msg を送り、それぞれの debug に出す 「h1抽出」は h1・「要素のテキストのみ」・「配列化した1つのメッセージ」で、「h1: メインタイトル」に ["メインタイトル"] が出る（1件でも配列になる）。「全p抽出」は p・「要素のテキストのみ」・「要素毎の複数のメッセージ」で、「p: 1件ずつ出力」に3つの msg（段落の文）が出る。「リンクURL抽出」は a・「要素の全ての属性」・「要素毎の複数のメッセージ」で、「href属性」に {"href":"https://example.com/page1"} などのオブジェクトが3つ出る パターン1
クラスやIDで絞り込み 「実行」（inject）→「クラス付きHTML」（template）→「.news-item .title」（html）→「ニュースタイトル」（debug） 「抽出する要素」は .news-item .title（クラス news-item の要素の中にある、クラス title の要素）。「ニュースタイトル」に、重要ニュース、通常ニュース1、通常ニュース2 の3つの msg が出る。同じ記事の中の summary の文は出ない パターン2
テーブルデータ抽出 「実行」（inject）→「テーブルHTML」（template）→「td抽出」（html）→「テーブルデータ」（debug） 「抽出する要素」は table tr td。「テーブルデータ」に、田中、30、エンジニア、鈴木…と、セル1つにつき1つの msg が、合わせて9つ出る。見出しの行（th）は含まれない。行ごとにはまとまらないので、どのセルがどの行かは、届いた順番（3つで1行）で見分ける パターン3

パターン1: 基本テキスト抽出（h1、p、リンク）

応用フローの「基本: HTMLからテキスト抽出」を参照してください。

サンプルHTML → h1抽出 → メインタイトル

用途: タグ名を指定した見出し・本文・リンクの抽出

ポイント:

  • h1 → 見出しテキストを抽出
  • p → 段落テキストを、1件ずつ別の msg で抽出（「要素毎の複数のメッセージ」を選んだ場合）
  • a ＋「出力」を「要素の全ての属性」→ href 属性（URL）の入ったオブジェクトを抽出

パターン2: クラスやIDで絞り込み

応用フローの「クラスやIDで絞り込み」を参照してください。

クラス付きHTML → .news-item .title → ニュースタイトル

用途: クラス名やID名による対象要素の絞り込み

ポイント:

  • .クラス名 でクラス指定
  • #ID名 でID指定
  • 入れ子は .parent .child のように空白で区切る

パターン3: テーブルデータ抽出

応用フローの「テーブルデータ抽出」を参照してください。

テーブルHTML → table tr td → テーブルデータ

用途: テーブルの各セルからのデータ抽出

ポイント:

  • table tr td でテーブルセルを抽出
  • 「出力」を「要素のテキストのみ」にして、テキストだけを取得
  • サンプルでは、セルごとに別の msg で届く。1つの配列で受け取りたいときは「配列化した1つのメッセージ」を選ぶ

6. まとめ

重要ポイント:

  • CSSセレクタでHTML要素を指定して抽出
  • text, html, 属性値 の3種類の出力形式
  • 複数要素がマッチした場合は、既定の設定では配列で出力
  • Webスクレイピングの基本ツール

注意事項:

  • Webスクレイピングは対象サイトの利用規約を確認
  • 動的に生成されるコンテンツ（JavaScript）は取得できない場合がある
  • サイト構造が変わるとセレクタが機能しなくなる可能性
