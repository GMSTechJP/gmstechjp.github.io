Git for Windows インストールガイド

このガイドでは、WindowsにGitを「コマンドプロンプトから git コマンドが使える状態」でインストールする手順を解説します。Node-REDのプロジェクト機能を使うための準備として書かれていますが、Gitのインストール手順そのものは他の用途でも同じです。

インストーラーの画面はすべて文章で説明します。画面に表示される項目名は英語の原文どおりに記載するので、手元の画面と見比べながら進めてください（Git for Windows 2.55時点）。

1. 「パスが通る」とは

Windowsには環境変数 Pathという設定があります。コマンドプロンプトで git のようにコマンド名だけを入力したとき、Windowsはこの Path に登録されたフォルダを順に探して、実行するプログラムを見つけます。探すフォルダの一覧にGitのフォルダが含まれている状態を、「パスが通っている」と言います。

パスが通っていないと、Gitをインストールしてあっても、コマンドプロンプトでは「'git' は、内部コマンドまたは外部コマンド、操作可能なプログラムまたはバッチ ファイルとして認識されていません。」というエラーになります。

Node-REDのプロジェクト機能はパスが通っていることが前提

Node-REDは起動時に、環境変数 Path を頼りにGitを探します。パスが通っていないと、Gitがインストール済みでもNode-REDからは「Gitがない」ように見え、settings.jsでプロジェクト機能を有効にしても起動時に無効へ戻されます。

「パスが通っているか」は、新しいコマンドプロンプトで git --version が実行できるかで確認できます（セクション4）。

Git for Windowsのインストーラーには、このパスを通すかどうかを決める選択画面があります。既定の選択のままなら自動でパスが通りますが、途中で別の項目を選ぶとパスが通らないままインストールが完了します。本ガイドではこの選択画面を重点的に説明します。

2. インストーラーのダウンロード

1

公式サイトからダウンロード

Git公式サイトのWindows向けダウンロードページを開き、「64-bit Git for Windows Setup」をクリックします。Git-<バージョン>-64-bit.exe という名前のインストーラーがダウンロードされます。

📥 Git for Windows をダウンロード

2

インストーラーを実行

ダウンロードしたファイルをダブルクリックして実行します。

管理者権限がなくても実行できます

管理者権限のない環境では、自分のユーザー専用としてインストールが進みます。この場合のインストール先は %LOCALAPPDATA%\Programs\Git になります。管理者としてインストールした場合は C:\Program Files\Git です。どちらでもパスの通し方は変わりません。

3. インストールウィザードの進め方

Git for Windowsのインストーラーは設定画面が10以上続きますが、選択を確認する必要があるのは「Adjusting your PATH environment」の1画面だけです。それ以外の画面は既定のまま「Next」で進めて問題ありません。各画面のタイトルと内容は次のとおりです。

画面タイトル（英語表示） 内容と操作
（ライセンス表示） GNU General Public Licenseの本文が表示されます。「Next」で進みます
Select Destination Location インストール先フォルダ。既定のまま「Next」
Select Components 追加コンポーネントの選択。既定のまま「Next」
Select Start Menu Folder スタートメニューの登録先。既定のまま「Next」
Choosing the default editor used by Git Gitがコミットメッセージの編集などに使うエディタ。どれを選んでもNode-REDの動作には影響しません。既定のまま「Next」
Adjusting the name of the initial branch in new repositories 新規リポジトリの最初のブランチ名。既定（Let Git decide）のまま「Next」
Adjusting your PATH environment ⚠️ この画面だけ必ず確認します（次項で詳述）
Choosing HTTPS transport backend HTTPS通信に使うライブラリ。既定のまま「Next」
Configuring the line ending conversions 改行コードの自動変換。既定のまま「Next」
Configuring the terminal emulator to use with Git Bash Git Bashが使う端末。既定のまま「Next」
Choose the default behavior of `git pull` git pull 実行時の既定動作。既定のまま「Next」
Choose a credential helper GitHub等への接続時に認証情報を記憶する仕組み。既定のまま「Next」
Configuring extra options その他のオプション。既定のまま「Next」
Configuring experimental options 実験的機能。チェックを入れずに「Install」でインストールを開始します

環境によっては、このほかに「Choosing the SSH executable」（PuTTYなどのSSHクライアントが検出された場合）や「Security options」（特定のセキュリティ設定が有効な場合）が表示されることがあります。いずれも既定のまま「Next」で問題ありません。

「Adjusting your PATH environment」画面での選択

この画面には「How would you like to use Git from the command line?」（コマンドラインからGitをどう使いますか？）という問いと、3つの選択肢が表示されます。2番目の「Git from the command line and also from 3rd-party software」を選びます。それぞれの意味は次のとおりです。

選択肢（英語表示） 動作 選択
Use Git from Git Bash only 環境変数 Path を一切変更しません。Gitは付属の「Git Bash」という専用画面からしか使えず、コマンドプロンプトやNode-REDなどの他のソフトからは見つけられません。これを選ぶとプロジェクト機能が動きません ❌
Git from the command line and also from 3rd-party software Gitのコマンド用フォルダ（cmd）だけを Path に追加します。Git Bashに加えて、コマンドプロンプト、PowerShell、そして Path からGitを探すサードパーティ製ソフト（Node-REDを含む）から使えるようになります。画面上に赤字で「(Recommended)」と表示され、初回インストールでは最初から選択されています ✅
Use Git and optional Unix tools from the Command Prompt Gitに加えて、付属のUnix系ツール一式も Path に追加します。Windows標準の find や sort コマンドが同名のUnixツールで置き換わる副作用があるため（画面上にも赤字で警告が表示されます）、影響を理解している場合以外は選びません ❌

再インストール時は「前回の選択」が復元される

インストーラーは前回インストール時の選択内容を記憶しており、入れ直すと各画面は推奨の既定値ではなく、前回選んだ状態で表示されます。過去に「Use Git from Git Bash only」を選んでしまった環境をインストーラーの再実行で直す場合は、既定に戻っているだろうと思い込んで「Next」を連打せず、この画面で必ず2番目を選び直してください。

4. インストール後の確認

1

コマンドプロンプトを新しく開く

スタートメニューで「cmd」と検索し、「コマンドプロンプト」を選択します。インストール前から開いていたウィンドウは使えません。環境変数 Path はウィンドウの起動時に読み込まれるため、インストールで追加された分は開き直すまで反映されないからです。

2

バージョンを確認

以下のコマンドを実行します。

C:\Users\YourName> git --version git version 2.55.0.windows.3

このように git version 2.x.x が表示されれば、Gitのインストールとパスの設定は完了です。

インストール完了

コマンドプロンプトから git コマンドが使える状態になりました。Node-REDからもGitを見つけられます。

5. トラブルシューティング

症状 原因 解決方法
'git' は、内部コマンドまたは外部コマンド、操作可能なプログラムまたはバッチ ファイルとして認識されていません。 インストール前から開いていたコマンドプロンプトを使っている ウィンドウを閉じて、新しいコマンドプロンプトを開き直す
インストール時に「Use Git from Git Bash only」を選んだ インストーラーを再実行し、「Adjusting your PATH environment」で2番目の「Git from the command line and also from 3rd-party software」を選び直す（前回の選択が復元されるため、この画面まで来たら必ず確認する）
インストーラーを再実行できない事情がある 環境変数 Path にGitのコマンド用フォルダを手動で追加する（下記の手順）
Node-REDのプロジェクト機能を有効にしても、起動時に無効へ戻される Node-REDがGitを見つけられていない まず新しいコマンドプロンプトで git --version を確認する。表示されるのにNode-REDで有効にならない場合は、Node-REDを一度停止し、新しいコマンドプロンプトから起動し直す（起動中のNode-REDはGitインストール前の Path を持ち続けているため）

環境変数 Path への手動追加

インストーラーでの選び直しができない場合は、次の手順でパスを手動で通せます。

1

環境変数の編集画面を開く

スタートメニューで「環境変数」と検索し、「アカウントの環境変数を編集」を選択します（管理者権限は不要です）。

2

Path にGitのフォルダを追加

上段（ユーザー環境変数）の一覧から「Path」を選んで「編集」→「新規」をクリックし、Gitのコマンド用フォルダを追加して「OK」で閉じます。追加するフォルダはインストール方法によって異なります。

インストール方法 追加するフォルダ
管理者としてインストールした場合 C:\Program Files\Git\cmd
ユーザー専用としてインストールした場合 %LOCALAPPDATA%\Programs\Git\cmd

どちらか分からない場合は、エクスプローラーで両方のフォルダを探し、git.exe が入っているほうを指定します。

3

反映を確認

新しいコマンドプロンプトを開き、git --version でバージョンが表示されることを確認します（セクション4と同じ手順です）。
